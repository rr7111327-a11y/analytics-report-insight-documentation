# Yuva Intern Task 5 - Analytics Report & Insights Documentation

## Project title
Student Performance Analytics and Insights

## Important data note
The included CSV is synthetic practice data generated for this educational project. It is not real student data.

## Requirements
- Python 3.9 or later
- Packages in `requirements.txt`

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `Yuva_Intern_Task_5_Analytics_Report_Project` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: `python -m pip install -r requirements.txt`
5. Run: `python main.py`
6. If `python` does not work on Windows, try: `py -m pip install -r requirements.txt` and `py main.py`.
7. Open the `outputs` folder to see charts, tables and findings.

## Files
- `main.py` - complete analysis program
- `data/student_performance.csv` - synthetic practice dataset (500 records)
- `outputs/` - generated charts, analysis tables and findings
- `TASK_5_DESCRIPTION_200_WORDS.txt` - description for the portal (more than 200 words)
- `Analytics_Report_Task_5.docx` and `.pdf` - report copies

## Reproducibility
The random dataset is generated once and included in the project. Running `main.py` reuses the same CSV and regenerates the analysis outputs.
