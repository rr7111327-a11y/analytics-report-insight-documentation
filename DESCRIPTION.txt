This project presents a complete analytics report and insights documentation workflow for Yuva Intern Task 5. The project uses a clearly labelled synthetic student-performance dataset containing 500 practice records. It is designed for learning and demonstration; it does not contain real student personal information and its results should not be treated as findings about an actual college.

The business objective is to demonstrate how an analyst can convert a dataset into understandable information that supports decisions. The analysis checks the dataset, removes duplicate and incomplete required records, calculates descriptive statistics, studies relationships between study hours, attendance, assignment scores, previous scores and final scores, and compares average performance across attendance groups. It also calculates simple performance indicators such as average score, median score, average attendance and a score-based pass rate.

The project creates four visualizations: a final-score distribution chart, an attendance-group comparison chart, a study-hours-versus-score scatter plot, and a factor-correlation chart. A Random Forest regression model is included as a supporting educational exercise. Its test-set MAE, RMSE and R-squared values are saved so that model performance can be reviewed rather than assumed.

The outputs folder contains generated charts, descriptive statistics, a correlation matrix, attendance-group analysis, model evaluation metrics and a plain-text key-findings document. The accompanying report explains the business objective, methodology, important findings, limitations, executive summary and actionable recommendations. Recommendations include reviewing low-attendance cases, supporting consistent study habits, using assignment feedback to identify learning gaps and protecting student privacy.

To reproduce the results, install the packages listed in requirements.txt and run `python main.py` from the project folder. The dataset and code are included in the ZIP so the project can be run locally in VS Code or another Python environment. All numerical findings are generated by the included program from the included synthetic dataset.
